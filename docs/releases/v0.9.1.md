GhidraMCP Extended 0.9.1 adds project lifecycle and findings workflows to the original MCP extension.
Forked from [the original GhidraMCP repository](https://github.com/themixednuts/GhidraMCP); original authorship and MIT license are retained.

- Import individual files or bounded directories with per-file results and explicit cancellation.
- Open project programs and close unchanged programs without save/discard dialogs.
- Inspect current analysis activity and recorded binary identity.
- Export selected functions, signatures, comments and structures as versioned JSON.
- Compare two selected functions using signatures, assembly and decompiler output, retaining unknown outcomes.

Install `GhidraMCP-0.9.1.zip` through Ghidra's extension manager, restart Ghidra, and reconnect the MCP client.
Built for **Ghidra 12.1.4**, with **Java 21** bytecode. Build, unit and offline integration checks are performed before publication.
Live verification in a user's running CodeBrowser is still outstanding.

Recorded hashes describe import metadata and do not re-verify current source files. An inactive analyzer does not prove past success.
Exports refuse existing destinations unless `overwrite:true` is provided; interrupted imports preserve completed work.
Comparison reports exact observations and makes no ABI or semantic compatibility claim.
See the repository README for examples and limits.
